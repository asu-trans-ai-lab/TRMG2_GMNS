# TRMG2 reproduction — stage gates & to-do (work in progress)

The reproduction is judged by a **control ladder**: each stage has a gate that leads with
**magnitude / control-total bias first**, then pattern. A red gate blocks *interpreting* the
stages below it (a good downstream R² never rescues missing upstream trips). This file is the
single checklist for the whole reproduction; measured interim numbers live in `review/`
(regenerated by the scripts named per gate, kept local).

Legend: ✅ pass · 🟡 stand-in / labeled · 🔴 open magnitude · ⬜ to build

## The gate ladder

| # | Stage | Gate (magnitude-first) | Status | Script |
|--:|---|---|:--:|---|
| 0 | Seed data | HH / persons / jobs vs SE control totals | ✅ | `stage_audit.py` |
| 1 | Generation | productions vs survey **wTrips** by purpose | ✅ | `demand_checks.py` |
| 2 | Distribution | avg trip length vs survey **wAvgTrpLen**; TLFD shape; OD_Long>OD_Short | ✅ (calibrated) | `demand_checks.py`, `compare_engines.py` |
| 3 | Mode | shares vs survey; **logsum diagnostic-only** until cost registry audited | 🟡 stand-in | — |
| 4 | Pre-assignment OD | preserves upstream totals; **missing markets labeled** | 🟡 labeled | `stage_audit.py` |
| 5 | Assignment / counts | **magnitude bias first**, then %RMSE / R² / GEH by facility | 🔴 −69% | `od_validation.py` |
| **④** | **VMT & VHT system** | **measured VMT & VHT by facility; freeway-weighted deficit** | 🔴 low/low | `vmt_vht_gate.py` |

### What Gate ④ found (the assignment diagnosis)
- **VMT and VHT are both low**, and the deficit is **not uniform** — it is **freeway-weighted**
  (freeway most under-loaded, local/collector least; ~14-point spread in count bias). A uniform
  capture would show ~0 spread.
- Therefore the shortfall is **long-distance markets**, not an assignment error: external /
  through / commercial-vehicle / NHB-long / airport. This is a **Gate ①/② coverage** problem
  surfacing at assignment.
- **VHT loses magnitude faster than VMT** → system speed biased **high** (freeways at free-flow,
  congestion never forms). The VMT/VHT matrix reads **"low/low = missing trips"**, trending to
  **"speeds too high / congestion underrepresented"** as short markets are added but long ones
  are still absent.

## Why this matters beyond TRMG2 (the reusable framework)
This is the **ABM/4-step trip-list → OD demand-inventory check** we want *before* running
TAPLite anywhere: map **socioeconomic data → trip distribution → VMT & avg-trip-length by
market** and gate on magnitude first. It is deliberately **multi-market** ("more than one type
of trip"), which is exactly what the city-tensor project needs, and it is the same check we
will apply to **SCAG, ARC, NVTA, and MAG** demand before handing OD into a DOT assignment —
so a biased VMT / trip-length distribution is caught at the demand stage, not blamed on the
network afterwards.
