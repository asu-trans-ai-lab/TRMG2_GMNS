This is a tool for learning — a way to study how a real regional travel model actually works, in the open. The goal is understanding, not converting any agency to GMNS. The Triangle Regional Model (TRMG2) is a tour-informed, trip-based model of four blocks and 21 modules; this page inventories the region, the network, and the demand, and marks how much of each module you can open and run yourself versus only read about. Module list per Zhang et al. (2024), Urban Transport of China 22(4):41–49, Table 1.

Who builds and governs it?model as an institution

Ownership & funding

Built by ITRE (NC State) as the Triangle Regional Model Service Bureau, funded by four agencies: NCDOT, the Capital Area MPO, the Durham–Chapel Hill–Carrboro MPO, and GoTriangle. Software development by Caliper (with WSP).

Lineage

2 generations, 7 versions. Gen-1 ran six versions (V6 final, 2020); Gen-2 launched 2020, V1 in 2021, V2.0 in July 2024. Released open-source on GitHub — code, inputs, and parameters — which is what makes this transfer possible.
