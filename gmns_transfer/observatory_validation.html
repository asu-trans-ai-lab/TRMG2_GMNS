You have an OD from the first three steps, but not the model owner's official pre-assignment matrix. Do not start from assignment. A bad loaded network can come from seed data, trip generation, distribution, or missing markets — not just assignment. So validation is a ladder: check each upstream rung before the next, so you fix the right problem instead of polishing a model that's missing trips.

The QA ladder — upstream firstgeneration → distribution → assignment
1
GATE ① · FIRST

Seed data & trip generation

Right number of trips before the network carries them?
  • production / attraction bias by purpose
  • by household, income, workers, auto, employment
  • district totals · top-zone review
  • RAG: ±5–10% green · ±10–20% amber · >20% red
2
GATE ② · SECOND

Trip distribution

Reasonable destinations & trip lengths before assignment?
  • average trip length by purpose
  • trip-length distribution (is the long tail there?)
  • intrazonal vs interzonal share
  • district-to-district markets · screenline OD
3
GATE ③ · THIRD

Assignment & counts

Does the loaded network carry the right traffic, in the right places?
  • magnitude bias first (see below)
  • then pattern: %RMSE, R², GEH<5
  • by facility, area, screenline, volume group
  • VMT / VHT system check
a red rung upstream  →  fix it before reading the next
Within Gate ③ — magnitude bias is still the first mark.
bias = ( Σ modeled − Σ counted ) / Σ counted
If the bias is large, the network isn't carrying the right total — go back upstream (generation? distribution? missing external / commercial / NHB markets? time-of-day? period aggregation?). Only after magnitude is in range do you read pattern metrics. A good R² never rescues a model that is missing trips.
④ VMT & VHT — system reasonablenessdiagnose demand vs network
VMTVHTLikely issue
LowLowmissing trips, or trips too short

⑤ The targetTRMG2's published %RMSE

Freeways validate tightest (high-volume, well-counted); local streets loosest (noisy). A freeway shortfall usually signals missing long-distance, through, external, commercial, or NHB markets — a Gate ①/② problem, not assignment.

⑥ When the official OD matrix arrives. Add a direct OD-to-OD check — matrix %RMSE, coincidence ratio, district-cell agreement, purpose-level & trip-length comparison — on top of the count validation, which stays the first line of verification.
